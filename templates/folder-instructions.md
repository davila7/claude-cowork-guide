# Template: Folder instructions

Add these instructions when selecting a folder in Cowork to provide project-specific context.

---

## Generic template

```
Project: [Project name]
Description: [One line describing what it's about]
Folder structure:
  - /docs → Project documentation
  - /data → Data files (csv, xlsx)
  - /output → Files generated by Claude
  - /assets → Images, logos, visual resources
Rules:
  - Don't modify files in /data (they are original sources)
  - Save all output in /output
  - Maintain a change log in /output/changelog.md
```

## Research project

```
Project: Research on [topic]
Status: [In progress / Collection phase / Analysis phase]
Key sources: [list relevant files or URLs]
Output format: Documents in markdown with citations and sources.
Folder structure:
  - /sources → Collected material
  - /notes → Notes and annotations
  - /deliverables → Final documents
Quality criteria: Every claim must be supported by at least one source.
```

## Product development project

```
Project: [Product name]
Phase: [Discovery / Definition / Development / Launch]
Team: [Roles involved]
Key files:
  - PRD.md → Requirements document (do NOT modify without confirming)
  - roadmap.xlsx → Project timeline
  - research/ → User research findings
Conventions:
  - File names: YYYY-MM-DD-type-description
  - Document format: Markdown for drafts, DOCX for final versions
```

## Finance folder

```
Project: Financial management [period]
Sensitive files: Treat all information as confidential.
Data:
  - /invoices → Received invoices (PDF)
  - /reports → Monthly reports
  - /budget → Budget files
Rules:
  - Do not delete any file under any circumstances
  - Verify calculations with formulas, don't hardcode values
  - Currency format: USD with 2 decimals
  - Date format: MM/DD/YYYY for documents, YYYY-MM-DD for file names
```
